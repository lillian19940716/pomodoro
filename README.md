# 專注 · Pomodoro Timer PWA

純 HTML / CSS / Vanilla JavaScript，無框架、無 CDN、無外部字型、無第三方 API。解壓縮後即為完整原始碼，不需要安裝前端套件或建置。

## 檔案與擺放位置

保留以下相對位置，將整個資料夾部署至 HTTPS 靜態網站根目錄或子目錄。

```text
pomodoro-pwa/
├── index.html                # 主畫面、設定視窗、安裝說明
├── style.css                 # 桌機與手機版面、安全區域、減少動態效果
├── script.js                 # 倒數、四輪循環、設定、聲音、通知、SW 註冊
├── manifest.json             # App 名稱、安裝範圍、啟動畫面與圖示
├── service-worker.js         # 版本化離線快取、通知點擊
├── icons/
│   ├── icon-192.png           # Android / PWA，192 × 192
│   ├── icon-512.png           # PWA，512 × 512
│   ├── icon-maskable-512.png  # 可裁切圖示，512 × 512；主圖在安全區內
│   └── apple-touch-icon.png  # iPhone / iPad，180 × 180
└── README.md
```

圖示已全部附上。即使漏傳圖示，網頁倒數仍能運作，核心離線快取也不會因圖示下載失敗而整批失敗；但安裝 App 的體驗可能受影響。

## 電腦本機測試

在解壓縮的 `pomodoro-pwa` 資料夾開啟終端機。如果電腦已安裝 Python 3：

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows 可使用 `py -m http.server 8000 --bind 127.0.0.1`。

在瀏覽器開啟 <http://localhost:8000>。按 Ctrl+C 可停止伺服器。也可使用既有的靜態網站伺服器；本專案沒有建置程序。直接雙擊 `index.html` 可使用基本倒數，但 `file://` 不支援 Service Worker，設定儲存行為也不一致，請用本機伺服器測試完整功能。

離線測試：先連線開啟，等待頁尾顯示「已可離線使用」，再將開發者工具 Network 設為 Offline 並重新整理。也可停止本機伺服器再重新整理驗證；瀏覽器可能在清除網站資料或儲存空間不足時移除快取，之後需重新連線準備。

## 部署與安裝

上傳整個資料夾到可提供 HTTPS 的靜態網站空間，保留檔名及資料夾結構；網址請使用根目錄或以 `/` 結尾的子目錄。支援子目錄部署，未使用寫死的根目錄路徑。

Service Worker 與通知要求安全來源，正式環境應使用有效 HTTPS。`localhost` 是本機開發例外；手機連電腦的區網 HTTP 位址通常不符合安全來源條件。不要以略過憑證警告作為安裝方法。

- **iPhone / iPad：**用 Safari 開啟 HTTPS 網址，點「分享」→「加入主畫面」，再由主畫面圖示啟動；若系統有「作為網頁 App 開啟」選項，保持開啟。選單文字會隨系統版本不同。
- **Android：**用 Chrome 開啟 HTTPS 網址，在選單選「安裝應用程式」或「加入主畫面」。是否顯示安裝入口由瀏覽器決定。
- **桌機：**支援 PWA 的瀏覽器可能在網址列或選單提供安裝入口；一般分頁也可完整計時。

## 操作規則

- 預設：專注 25 分鐘、短休息 5 分鐘、長休息 15 分鐘。
- 開始後自動接續各階段；完成第 4 次專注後進入長休息。長休息結束後回到專注，完成輪數歸零。
- 暫停保留精確剩餘毫秒；繼續從原處計時，畫面向上取整顯示秒數。
- 重設只重設目前模式並暫停，不清除已完成輪數。
- 跳過進入下一段，保留原本的執行／暫停狀態。跳過專注不增加完成輪數；跳過長休息會開始新循環。
- 手動切換模式會放棄目前剩餘時間，重設選定模式並暫停；保留完成輪數。長休息完成或被跳過才重開循環。
- 設定可輸入 1–180 的整數分鐘。尚未開始的階段立即套用；正在進行或暫停中的階段不被改寫，下一段或按重設時使用新時間。
- 設定使用 localStorage，僅保存在目前瀏覽器／來源中，不跨裝置同步。儲存被封鎖時會提示，仍可使用本次設定。
- 重新整理、關閉再開啟會以專注模式及 0 / 4 重新開始；只保存自訂分鐘數。

## 提示音、通知與 iOS 限制

在設定中按「開啟通知」才會要求權限。允許後，專注完成顯示「專注完成／休息一下吧。」；休息結束顯示「休息結束／準備開始下一輪專注。」。拒絕後不反覆要求，可到瀏覽器或系統設定自行修改。

提示音由 Web Audio API 產生兩個低音量正弦音，使用淡入淡出。AudioContext 在第一次按「開始」時初始化；音量、靜音、裝置狀態與瀏覽器自動播放規則都可能影響播放。程式不下載任何音訊檔。系統通知採靜音選項，避免與提示音重複發聲；實際行為依系統決定。

iOS / iPadOS 的主畫面 Web App 自 16.4 起有 Web Push 支援，授權必須由使用者操作觸發。**本專案沒有推播伺服器或 Push 訂閱，也不是原生鬧鐘。**普通 Safari 分頁不宣稱能背景通知；主畫面模式雖可能提供通知 API，通知顯示仍受瀏覽器與系統限制。若不支援、拒絕權限或顯示失敗，保留計時、畫面文字提醒，以及音訊允許時的提示音。

倒數依 `Date.now()` 與結束時間戳計算，不依賴每秒扣一。切換分頁後會校正目前剩餘時間，但無法阻止手機暫停網頁 JavaScript。**鎖屏、背景暫停、關閉網頁時，不保證準時發聲或通知。**恢復時若目前階段已結束，只完成這一段，立即啟動下一段完整時間；不把離開期間虛算為多輪專注。裝置時鐘被手動或系統大幅調整會影響倒數。

Service Worker 只負責快取與顯示已觸發的通知，不維持背景倒數，沒有不可靠的背景 setInterval。需要可靠鎖屏鬧鐘時，請使用系統計時器。

官方參考：[WebKit：iOS / iPadOS Web Push](https://webkit.org/blog/13878/web-push-for-web-apps-on-ios-and-ipados/)、[MDN：showNotification](https://developer.mozilla.org/en-US/docs/Web/API/ServiceWorkerRegistration/showNotification)。

## 程式修改位置

| 項目 | 位置 |
| --- | --- |
| 預設分鐘與輸入驗證 | `script.js` 的 `DEFAULTS`、`validMinutes()` |
| 自動四輪循環與跳過 | `advance()`、`enterMode()` |
| 時間戳校正與分頁 title | `tick()`、`render()` |
| 設定儲存 | `loadSettings()`、`settings-form` 的 submit 事件 |
| 提示音 | `unlockAudio()`、`playChime()`；0.075 為音量峰值 |
| Notification | `updateNotificationUI()`、`notify()`、`notifications` 的 click 事件 |
| Service Worker 註冊 | `registerServiceWorker()` |
| 離線快取清單及版本 | `service-worker.js` 的 `CORE_FILES`、`ICON_FILES`、`CACHE_NAME` |

更新核心檔案時，請一併增加 `CACHE_NAME` 的版本字串並部署所有檔案。採同版快取優先以避免新舊程式混用，新版不強制接管正在計時的舊分頁；關閉此網站所有分頁與 PWA 視窗後再開啟，新版才會接管。沒有更新資料同步或後端相依。

## 驗證紀錄與建議

自動邊界測試使用實際 `script.js` 與模擬時鐘，驗證暫停／繼續、四輪及長休息、自動接續、跳過不計數、手動模式、儲存與重新讀取、錯誤設定、儲存被封鎖、背景恢復與權限只由按鈕觸發。這些是邏輯測試，不能取代實機測試。

正式使用前，建議在自己的 iPhone / Android 以 HTTPS 測試安裝、通知授權、靜音及鎖屏。不同系統的通知及音訊政策不能單靠桌機測試保證。

本次亦已在內建瀏覽器驗證：開始／暫停、自訂時間重新整理後保留、320 × 568 小尺寸版面及設定面板；停止本機伺服器後重新載入並開始計時成功。未進行 iPhone / Android 實機安裝、鎖屏通知或系統通知授權測試。
